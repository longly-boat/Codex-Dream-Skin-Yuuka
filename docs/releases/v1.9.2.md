# Codex Dream Skin Yuuka v1.9.2

**中文** · [English](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.2/docs/releases/v1.9.2-en.md)

v1.9.2 是优香版的首发版本，基于超天酱主题项目 v1.9.1，为 Windows Codex Desktop 提供优香与蔚蓝档案风格的首页、工作台和聊天界面。

> 这是一个**纯 vibe coding 产物**：优香版的定制与修复主要通过 AI 辅助实现，仍可能有 bug。如果影响了你的使用，先说声抱歉。欢迎在 [Issues](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/issues) 提供复现步骤、Codex 与主题版本，以及去除个人信息后的截图。已有检查不代表所有电脑和后续 Codex 版本都经过人工验证。

## 新增功能

- **优香浅色与夜间主题**：默认「优香 · 千年研讨会」，内置「优香 · 夜间核算」；管理器支持切换主题、导入本地 ZIP、调整透明度和动效。重新启动时保留已选主题和设置。
- **首页与聊天页差分**：首页显示优香壁纸、眨眼、发丝微动和千年徽记动效；聊天页使用背景色。首页顶栏透明，项目内的新聊天标题带上项目名称。
- **四张主题任务卡**：夏莱调查、千年工坊、优香核算、应急支援，对应探索、构建、审查和修复任务。
- **Workspace 与优香寄语**：Workspace 使用原生项目与菜单；首页 Memo 显示同人寄语，可通过「换一句」切换。
- **今日计划**：支持添加、勾选和删除，重启后保留。每台设备的当前 Codex 本机存储中保存一份个人清单，所有项目共用；最多 100 项，每项 120 字，不自动跨日清空。它不会发送聊天、创建 Codex 目标或同步到其他设备；清除 Codex 应用数据会清除清单。

## 修复与改进

- 调整首页卡片、Memo、今日计划与原生建议区域的响应式排版，减少切换项目和改变窗口大小时的重叠。
- 补充侧栏、顶栏、菜单、Git 浮层、目标进度与输入区的蓝白主题细节；保留原生项目、建议和操作控件。
- 改进原版 Store 入口的进程识别、自动接管与隐藏启动，避免依赖固定的 Codex 包版本。原版任务栏入口可以继续使用；自动接管仍需关闭旧实例并重启一次，不是无重启注入。
- 使用独立产品名、安装目录、数据目录、图标、安装器 AppId 和更新源。优香版不注册或覆盖原版 `dreamskin://` 协议，可从管理器导入本地主题 ZIP。
- 默认包包含 `theme.css` 和浅深两套预设，打包时校验主题、壁纸、图标与 Node 摘要；不携带上游壁纸、托盘图标或旧本机编译的启动器。

## 安装与迁移

本次仅提供 **Windows x64** 安装包。需要 Windows 10 或更高版本，以及已经安装并成功启动过的 Microsoft Store 版 Codex。安装器内置 Node.js 和自包含主题管理器，日常使用无需另装开发工具。macOS/Linux 的上游代码与共享资源保留在仓库中，但其默认主题、产品身份和更新器未作为优香版发行。

下载 `CodexDreamSkinYuuka-Setup-v1.9.2.exe` 与同一 Release 的 `SHA256SUMS.txt`，核对摘要后运行。安装器**未做代码签名**，Windows 可能显示未知发布者或 SmartScreen 提示；摘要校验和运行时校验不等于发布者签名。

此前本机定制版使用 `%LOCALAPPDATA%\CodexDreamSkin`。迁移步骤：

1. 保存输入并完全退出 Codex；在旧版中停用自动接管，使用旧版恢复入口恢复原生外观。
2. 安装优香版，使用新的 `%LOCALAPPDATA%\Programs\CodexDreamSkinYuuka` 安装目录和 `%LOCALAPPDATA%\CodexDreamSkinYuuka` 数据目录。旧引擎仍在接管或留有待恢复状态时，新版会提示先处理旧版。
3. 新数据目录首次创建时，若旧活动主题为优香，复制经过校验的活动主题、已保存主题及动效、透明度、语言、暂停偏好；已存在的新目录不被覆盖，旧目录保留。旧库中可识别的未改动、无 CSS 的上游默认预设留在旧目录，不作为优香包迁入。
4. 打开 **Codex Dream Skin Yuuka** 确认所选主题，再按需启用自动接管。Setup 升级时会保存、停用并恢复原先的优香接管设置；同一 Codex 同时只使用一个主题引擎。

迁移不复制引擎、PID、端口状态、登录、聊天、浏览器 profile 或旧配置备份。今日计划沿用现有 Codex 本机存储键，不因主题工具改名清空。更多操作见 [使用、迁移与源码构建](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.2/YUUKA-README.md)。

## 动效、桌宠与素材

托盘「动态效果」选择「完整」，并启用「角色反应」，可查看首页眨眼和发丝微动。系统减少动态效果、页面隐藏和暂停设置仍优先。专属动画按主题 ID 和壁纸摘要匹配；替换背景后，不会把原有眼睛动画叠到无关图片上。

独立桌宠依赖 Codex 账号中的桌宠功能，**不包含在本安装包中，也不会自动导入账号**。单独导入三文件主题 ZIP 也不能替代优香引擎中的专属工作台与动效。

壁纸和闭眼素材为 AI 生成的同人图，角色及游戏标识归各自权利人；软件 MIT 许可证不授予这些第三方权利。本项目不是 OpenAI、NEXON 或 NEXON Games 的官方产品。详见 [安装包说明](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.2/windows/NOTICE.md)。
