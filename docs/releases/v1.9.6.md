# Codex Dream Skin Yuuka v1.9.6

**中文** · [English](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.6/docs/releases/v1.9.6-en.md)

修复 Codex 更新后首页壁纸被覆盖、选中会话标题出现双层高亮的问题。已在 Windows Codex 26.1117.3838.0 实测：首页恢复壁纸和人物动效，会话保留纯色背景，侧栏选中项仅显示一层高亮。

本项目为**纯 vibe coding、AI 辅助实现**的优香定制版，仍可能有遗漏。如果遇到 bug，先说声抱歉；欢迎在 [Issues](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/issues) 提供复现步骤、Codex 与主题版本，以及已去除个人信息的截图或日志。

## 修复与改进

- **首页壁纸恢复**：适配新版 Codex 新增的工作区背景层，避免它遮住首页插画。会话与设置页继续使用主题背景色，原生布局和控件点击区域保持不变。
- **侧栏选中项**：兼容会话行与内部标题同时标记为当前项的结构，移除标题上的重复背景、描边和左侧标记。悬停不会重新叠加高亮，原生键盘焦点、会话点击和右侧操作继续可用。
- **回归覆盖**：补充真实浏览器检查，覆盖首页、会话、设置页、关闭动效、移除主题，以及新版嵌套选中项和旧版单层选中项。

## 升级与使用

仅提供 **Windows x64** 安装包。下载 `CodexDreamSkinYuuka-Setup-v1.9.6.exe` 与同一 Release 的 `SHA256SUMS.txt`，核对摘要后运行。安装器**未做代码签名**。

从优香 v1.9.5 或更早版本升级时，保存当前输入、退出 Codex，再安装到原来的优香目录。升级沿用现有主题设置、自动接管偏好和今日计划存储。使用原版任务栏入口的接管方式没有变化，仍会重启一次 Codex。

macOS/Linux 同步共享样式和版本号，未发布对应的优香安装包。独立桌宠没有改动。
