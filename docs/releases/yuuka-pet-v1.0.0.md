# 优香桌宠 v1.0.0 · 素材与构建工具公开

[English release notes](yuuka-pet-v1.0.0-en.md)

配套优香桌宠现已单独公开。通过[桌宠分享页](https://chatgpt.com/s/sharepet_6af711e160f88191a4508c5d0af094b2)添加到自己的桌宠库，或下载 `Yuuka-Pet-v1.0.0.zip` 获取完整图集、可编辑源图与工具。

这是独立桌宠素材版本，**不是主题安装器升级**；Windows 主题当前仍为 v1.9.2。

## 包含内容

- 透明 v2 图集：9 种常规动作、16 个视线方向，1536×2288、单格 192×208。
- 新版六帧待机：呼吸、眨眼、轻歪头、抬手轻触衣领，再自然放下手。
- 与发布图集逐像素一致的可编辑 PNG、公开动作布局和待机改进提示词。
- 全动作 GIF、待机静态图、联系表及独立 Python/Pillow 无损重建工具。
- 中英使用说明、MIT 软件许可证、同人素材声明及 SHA-256 校验文件。

## 使用与验证

桌宠需要账号和应用支持 Pets 功能，不由主题 Setup 自动安装。完整说明见 [pets/yuuka](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/tree/yuuka-pet-v1.0.0/pets/yuuka)。

公开 WebP 与当前使用版本逐像素一致，平台结构校验通过（73 个有效格、15 个透明空格）。源 PNG 无损重建验证通过，公开文件已检查不含私人账号记录、临时资源地址或本机配置。其余十行动作沿用现有版本，未重新绘制或宣称获得新的全动作视觉认证。

下载后可用 `SHA256SUMS.txt` 核对 ZIP；包内也提供逐文件摘要。修改图集后请重新校验和预览。
