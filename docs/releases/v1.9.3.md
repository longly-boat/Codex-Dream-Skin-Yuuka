## 修复与改进

- **操作锁忙时不再立即放弃接管。** 当托盘初始化等操作短暂占锁，启动器仅对首次拿锁前、通过令牌校验的锁忙结果进行有限重试：最多 4 次，重试调度预算为 90 秒。没有冲突时不会新增等待；预算用尽会停止尝试。
- **保留单次重启保护。** 各次尝试沿用同一预约，并重新核验原始 Codex 进程。已经拿过锁或开始接管后的失败不会被当作锁忙重试；停止、暂停及身份校验仍生效。这不是无限重启，也不是无重启注入。
- **识别已被复用的旧注入器 PID。** 有效的已保存 UTC 创建时间与当前进程创建时间明确不同时，将旧记录判为过期并保留无关程序。时间缺失、格式错误或无法核验时仍保留安全拒绝；不会仅凭进程编号结束程序。
- **补充诊断与回归。** 记录启动锁等待、托盘初始化耗时和重试次数；新增真实锁争用、伪造或损坏结果、暂停/停止以及 PID 复用等自动化回归，便于定位后续启动问题。

## 升级与使用

本次仅提供 **Windows x64** 安装包。下载 `CodexDreamSkinYuuka-Setup-v1.9.3.exe` 与同一 Release 的 `SHA256SUMS.txt`，校验摘要后运行。安装器**未做代码签名**，Windows 可能显示未知发布者或 SmartScreen 提示。

从优香 v1.9.2 升级时，保存当前输入、退出 Codex 后安装到原来的优香目录即可。Setup 会保留现有主题与偏好，并恢复升级前的自动接管设置；今日计划仍使用原来的 Codex 本机存储，不因本次升级清空。若此前没有启用自动接管，在主题管理器中启用后再使用原版任务栏入口。

原版 Store 入口仍需先启动 Codex，再由主题工具关闭旧实例并重启一次。本次修复提高接管可靠性，不承诺所有设备上的固定启动时长。不修改官方 Codex 安装文件。

首次安装或从旧定制版迁移，参见 [Windows 安装指南](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.3/docs/install-windows.md) 与 [使用及迁移说明](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.3/YUUKA-README.md)。macOS/Linux 本次仅同步版本号，未发布优香安装包；独立桌宠不随本次更新重新打包。
