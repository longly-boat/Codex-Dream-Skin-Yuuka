# Codex Dream Skin Yuuka v1.9.5

[中文](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.5/docs/releases/v1.9.5.md) · **English**

Fixes Yuuka's home wallpaper remaining visible after opening a conversation. Home keeps its wallpaper and character animation, while conversations return to a solid background, including when motion is paused or turned off.

This Yuuka customization is a **pure vibe coding project implemented with AI assistance** and may still contain bugs. Sorry if you encounter one; please share reproduction steps, your Codex and theme versions, and screenshots or logs with personal information removed in [Issues](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/issues).

## Fixes and improvements

- **Solid conversation background**: Backgrounds follow the active page independently of the motion controller's pause state. Opening a conversation also removes the home wallpaper, character decorations, and transparent header treatment.
- **Cached page compatibility**: Inactive home pages retained in the background no longer cause an open project or conversation to be mistaken for Home.
- **Motion pause and resume**: A hidden overlay main surface no longer replaces the real page as the visibility anchor. Offscreen pages and IME composition still pause motion. Page identity updates during IME composition do not trigger layout measurements.
- **Regression coverage**: Added checks for paused and disabled motion, cached pages, and hidden overlays, plus a real-browser check of the final painted backgrounds.

## Upgrading and usage

This release provides a **Windows x64** installer only. Download `CodexDreamSkinYuuka-Setup-v1.9.5.exe` and the matching `SHA256SUMS.txt`, verify the checksum, and run Setup. The installer is **not code-signed**.

To upgrade from Yuuka v1.9.4, save your input, quit Codex, and install into the existing Yuuka directory. The upgrade retains existing theme settings, automatic-takeover preferences, and Daily Plan storage. Takeover from the stock taskbar entry is unchanged and still restarts Codex once.

macOS/Linux receive the shared runtime changes and aligned version numbers; no Yuuka packages are published for those platforms in this release. The independent companion pet is unchanged.
