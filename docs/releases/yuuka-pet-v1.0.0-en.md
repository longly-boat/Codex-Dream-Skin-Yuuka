# Yuuka pet v1.0.0 · Public assets and tooling

[中文版本说明](yuuka-pet-v1.0.0.md)

The matching Yuuka companion is now available separately. [Add the shared pet](https://chatgpt.com/s/sharepet_6af711e160f88191a4508c5d0af094b2), or download `Yuuka-Pet-v1.0.0.zip` for the complete atlas, editable source and tooling.

This is an independent pet asset release, **not a theme installer update**. The current Windows theme remains v1.9.2.

## Included

- A transparent v2 atlas: nine standard states and sixteen look directions, 1536×2288 with 192×208 cells.
- A richer six-frame idle with breathing, blinking, a shy head tilt and a gentle collar touch.
- An editable PNG with identical decoded pixels, public layout metadata and retained idle-refinement prompts.
- All-state GIFs, idle stills, a contact sheet and standalone Python/Pillow lossless rebuilding tools.
- Chinese and English instructions, the MIT software license, artwork notices and SHA-256 checksums.

## Use and verification

The account and application must support Pets. The Windows theme Setup does not install account pets. See [pets/yuuka](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/tree/yuuka-pet-v1.0.0/pets/yuuka) for instructions.

The published atlas matches the currently used companion's decoded pixels and passes platform structural validation: 73 populated cells and 15 transparent unused cells. Lossless rebuilding from the source PNG was verified. The public inventory excludes private account records, temporary resource URLs and machine configuration. The ten retained rows were not redrawn or newly certified for every aspect of animation semantics.

Use the Release `SHA256SUMS.txt` to verify the ZIP; the package also includes per-file checksums. Validate and preview the atlas again after editing it.
