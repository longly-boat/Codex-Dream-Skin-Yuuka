# Codex Dream Skin Yuuka v1.9.5

**中文** · [English](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.5/docs/releases/v1.9.5-en.md)

修复从首页进入会话后仍显示优香壁纸的问题。首页保留壁纸和人物动效，会话恢复纯色背景；动效暂停或关闭时也能正常切换。

本项目为**纯 vibe coding、AI 辅助实现**的优香定制版，仍可能有遗漏。如果遇到 bug，先说声抱歉；欢迎在 [Issues](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/issues) 提供复现步骤、Codex 与主题版本，以及已去除个人信息的截图或日志。

## 修复与改进

- **会话纯色背景**：背景根据当前活动页面切换，不再依赖动效控制器的暂停状态。返回会话时会同步撤去首页壁纸、人物装饰及透明顶栏。
- **页面缓存兼容**：忽略后台保留的非活动首页，避免切换项目或会话后仍被判为首页。
- **动效暂停与恢复**：隐藏的浮层主区域不再取代实际页面作为可见性判断依据；页面离屏和输入法组合输入期间仍暂停动效。输入法组合输入期间的页面状态更新不会触发布局测量。
- **回归覆盖**：补充暂停、关闭动效、缓存页面及隐藏浮层场景的检查，并在真实浏览器中校验最终背景样式。

## 升级与使用

本次仅提供 **Windows x64** 安装包。下载 `CodexDreamSkinYuuka-Setup-v1.9.5.exe` 与同一 Release 的 `SHA256SUMS.txt`，核对摘要后运行。安装器**未做代码签名**。

从优香 v1.9.4 升级时，保存当前输入、退出 Codex，再安装到原来的优香目录。升级沿用现有主题设置、自动接管偏好和今日计划存储。使用原版任务栏入口的接管方式没有变化，仍会重启一次 Codex。

macOS/Linux 同步共享运行时代码和版本号，本次未发布对应的优香安装包。独立桌宠没有改动。
