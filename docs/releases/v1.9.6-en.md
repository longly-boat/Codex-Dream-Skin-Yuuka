# Codex Dream Skin Yuuka v1.9.6

[中文](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.6/docs/releases/v1.9.6.md) · **English**

Fixes the home wallpaper being covered and conversation titles showing duplicate selection highlights after a Codex update. Verified in Windows Codex 26.1117.3838.0: Home displays the wallpaper and character animation, conversations keep a solid background, and selected sidebar rows have one highlight.

This Yuuka customization is a **pure vibe coding project implemented with AI assistance** and may still contain bugs. Sorry if you encounter one; please share reproduction steps, your Codex and theme versions, and screenshots or logs with personal information removed in [Issues](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/issues).

## Fixes and improvements

- **Home wallpaper restored**: Adapts to the workspace backing layer added by updated Codex so it no longer covers the home illustration. Conversations and Settings retain the theme background color. Native layout and control hit areas remain unchanged.
- **Sidebar selection**: Handles the conversation row and its nested title both being marked as current. Removes the duplicate title background, outline, and left marker. Hover does not add a second highlight; native keyboard focus, conversation clicks, and trailing actions remain available.
- **Regression coverage**: Adds real-browser checks for Home, conversations, Settings, disabled motion, theme removal, nested selection in updated Codex, and older single-level selection.

## Upgrading and usage

This release provides a **Windows x64** installer only. Download `CodexDreamSkinYuuka-Setup-v1.9.6.exe` and the matching `SHA256SUMS.txt`, verify the checksum, and run Setup. The installer is **not code-signed**.

To upgrade from Yuuka v1.9.5 or earlier, save your input, quit Codex, and install into the existing Yuuka directory. The upgrade retains existing theme settings, automatic-takeover preferences, and Daily Plan storage. Takeover from the stock taskbar entry is unchanged and still restarts Codex once.

macOS/Linux receive the shared styles and aligned version numbers; no Yuuka packages are published for those platforms. The independent companion pet is unchanged.
