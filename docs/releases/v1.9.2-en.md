# Codex Dream Skin Yuuka v1.9.2

[中文](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.2/docs/releases/v1.9.2.md) · **English**

v1.9.2 is the first Yuuka release, based on v1.9.1 of the Internet Angel theme project. It brings Yuuka and Blue Archive styling to Home, the workspace and conversations in Windows Codex Desktop.

> This is a **pure vibe coding project**: the Yuuka customization and fixes were implemented mainly with AI assistance, and bugs may remain. Sorry if they get in your way. Please report reproduction steps, your Codex and theme versions, and screenshots with personal information removed in [Issues](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/issues). Existing checks do not mean every computer or future Codex release has been manually verified.

## New features

- **Light and night themes**: Yuuka · Millennium Seminar is the default, with Yuuka · Night Accounting included. The manager supports theme switching, local ZIP imports, transparency and motion settings. Your selection and settings survive restarts.
- **Different Home and conversation views**: Home has Yuuka wallpaper, blinking, subtle hair movement and an animated Millennium emblem. Conversations use a background color. The Home top bar is transparent, and new chats inside a project include its name in the greeting.
- **Four themed task cards**: Schale Investigation, Millennium Workshop, Yuuka Accounting and Emergency Support correspond to exploring, building, reviewing and fixing.
- **Workspace and Yuuka's Memo**: Workspace uses native projects and menus. Memo contains fan-written messages; use the change-message button to switch them.
- **Daily Plan**: Add, complete and delete items, with changes retained after restarting. One personal list is stored in the current Codex application's local storage on each device and shared across projects: up to 100 items, 120 characters each. It does not reset each day, send chats, create Codex goals or sync across devices. Clearing Codex app data removes the list.

## Fixes and improvements

- Adjusted responsive spacing among Home cards, Memo, Daily Plan and native suggestions to reduce overlap when switching projects or resizing the window.
- Added blue-and-white styling for the sidebar, top bar, menus, Git overlays, goal progress and composer while retaining native projects, suggestions and controls.
- Improved process detection, automatic takeover and hidden startup for the original Store launch entry, without pinning one Codex package version. The original taskbar icon remains usable. Takeover still closes the old instance and restarts Codex once; it is not restart-free injection.
- Added a separate product name, installation and data directories, icon, installer AppId and update source. Yuuka does not register or replace the upstream `dreamskin://` protocol. Local theme ZIPs can be imported through the manager.
- Included `theme.css` and both presets in the default package, with theme, wallpaper, icon and Node hash checks during packaging. Upstream wallpaper, tray icons and the old locally compiled launcher are excluded.

## Installation and migration

This release provides a **Windows x64** installer only. It requires Windows 10 or later and the Microsoft Store version of Codex installed and successfully launched at least once. Node.js and a self-contained theme manager are bundled; normal use does not require development tools. Inherited macOS/Linux code and shared assets remain in the repository, but their default themes, identities and updaters are not shipped as Yuuka distributions.

Download `CodexDreamSkinYuuka-Setup-v1.9.2.exe` and `SHA256SUMS.txt` from the same Release, and verify the checksum before running Setup. The installer is **not code-signed**. Windows may show an unknown-publisher or SmartScreen prompt; checksums and runtime validation do not provide a publisher signature.

Earlier local customizations used `%LOCALAPPDATA%\CodexDreamSkin`. To migrate:

1. Save your input and fully exit Codex. Disable automatic takeover in the old version, then use its restore entry to restore the original appearance.
2. Install Yuuka into the new `%LOCALAPPDATA%\Programs\CodexDreamSkinYuuka` directory. Its data directory is `%LOCALAPPDATA%\CodexDreamSkinYuuka`. If the old engine still has takeover enabled or pending restoration state, Yuuka asks you to resolve that first.
3. When the new data directory is first created, an existing Yuuka active theme enables migration of validated active and saved themes, motion, transparency, language and pause preferences. An existing new directory is not overwritten, and the old directory is retained. Recognized, unchanged upstream defaults without CSS remain in the old library rather than being imported as Yuuka packages.
4. Open **Codex Dream Skin Yuuka**, confirm the selected theme and optionally enable automatic takeover. Setup upgrades save, disable and restore your existing Yuuka takeover setting. Use only one theme engine with the same Codex instance at a time.

Migration does not copy the engine, PIDs, port state, login data, chats, browser profiles or old configuration backups. Daily Plan retains its existing Codex local-storage key, so renaming the theme tool does not clear it. The [Chinese usage, migration and source-build guide](https://github.com/longly-boat/Codex-Dream-Skin-Yuuka/blob/v1.9.2/YUUKA-README.md) contains additional operational details.

## Motion, pets and artwork

In the tray's motion controls, choose **Full** and enable **Character reactions** to see blinking and subtle hair movement on Home. System reduced-motion preferences, hidden pages and pause settings still take precedence. Character animations are matched to the theme ID and wallpaper hash, so replacing the background does not overlay the original eyes onto an unrelated image.

The separate desktop pet depends on your Codex account's pet feature. It is **not included in this installer and is not automatically imported into your account**. Importing a three-file theme ZIP alone also does not provide the custom workspace and motion implemented by the Yuuka engine.

Wallpaper and closed-eye artwork are AI-generated fan materials. Character and game marks belong to their respective owners; the MIT software license does not grant those third-party rights.
